Exploratory Data Analysis (EDA)
About
This repository contains Python notebooks for exploring datasets and practising data preprocessing techniques using Pandas and Scikit-learn.
Files
- EDA.ipynb – Exploratory analysis of the loan approval dataset.
- Transformed_data_pickle.ipynb – Data transformation and preprocessing practice using the Titanic dataset.
- Loading_from_pickle.ipynb – Loading saved data with Pickle.
- custom_functions.py – Reusable Python functions.
- CSV and PKL files – Datasets and saved processed data used in the notebooks.
Tools
Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Pickle.
Run the Project
git clone https://github.com/Bhavanashahapurkar/Exploratory-Data-Analysis.git
cd Exploratory-Data-Analysis
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
